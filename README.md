# Real-Time Facial Emotion Recognition System

## Project Overview

The Real-Time Facial Emotion Recognition System is an AI-based computer vision project that detects human faces in real time and predicts emotions using deep learning techniques. The system uses a custom CNN model with OpenCV and TensorFlow for live emotion detection through webcam video streams.

---

## Features

* Real-time face detection
* Emotion prediction using CNN model
* Live webcam integration
* Multiple emotion classification
* Fast and accurate prediction system
* User-friendly interface

---

## Emotions Detected

* Happy
* Sad
* Angry
* Neutral
* Surprise
* Fear
* Disgust

```bash

```

## Project Workflow

1. Capture live video from webcam
2. Detect human face using OpenCV
3. Preprocess detected face image
4. Pass image to CNN model
5. Predict emotion in real time
6. Display emotion label on screen
